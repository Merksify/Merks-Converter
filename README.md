# Merks Converter

A fast terminal-based file converter. Drag and drop any image file into the terminal prompt to convert it to any supported format (PNG, JPG, WEBP, PDF, etc.).

## Installation

### Windows
Double-click `install.bat`. This installs required dependencies (`Pillow`) and sets up a global command.

### macOS / Linux
Open terminal in the project directory and run:
```bash
bash install.sh
```

## Usage

Once installed, open any terminal or command prompt window and type:

```bash
convert-merks
```

1. Drag and drop your file into the terminal.
2. Type the target format (e.g. `png`, `jpg`, `pdf`).
3. The converted file will be created right alongside the original!

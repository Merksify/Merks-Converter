A fast terminal-based file converter. Drag and drop any image file into the terminal prompt to convert it to any supported format (PNG, JPG, WEBP, PDF, etc.).

## Direct Installation (No manual download required!)

You can install Merks Converter directly from your terminal straight from GitHub using `pip`:

```bash
pip install git+https://github.com/Merksify/Merks-Converter.git
```

## Usage

Once installed, open any terminal or command prompt window from anywhere on your computer and type:

```bash
convert-merks
```
*(or `convert_merks`)*
